## 🔧 Troubleshooting

### Common Issues:

1. **"python3: command not found"**
   ```bash
   # Install Python from python.org or use:
   brew install python  # macOS with Homebrew
   ```

2. **Virtual environment not working**
   ```bash
   # Create fresh environment:
   python3 -m venv venv
   source venv/bin/activate
   ```

3. **Permission errors**
   ```bash
   # Make setup script executable:
   chmod +x setup.py
   ```

4. **Module not found**
   ```bash
   # Install missing packages:
   pip install <package-name>
   ```
